# LifeOS
LifeOS is a productivity application that helps users manage tasks, build habits, and achieve goals by turning daily activities into a game-like experience. 
Users earn XP (Experience Points), maintain streaks, unlock achievements, and level up by completing important tasks on time.
The project uses Data Structures and Algorithms (DSA) to improve task management and decision-making. 
A Priority Queue is used to display the most important tasks first, a Graph is used to represent skill progression and learning paths, a Hash Map stores user data and achievements, a Queue manages daily tasks, a Stack enables undo operations, and a Heap is used for productivity rankings and leaderboards.

The main objective of LifeOS is to reduce procrastination, improve productivity, and motivate users through gamification while demonstrating practical applications of DSA concepts in a real-world problem.

Used concept as :
Priority Queue, Graph, Hash Map, Stack, Queue, Heap, Sorting, and Binary Search
